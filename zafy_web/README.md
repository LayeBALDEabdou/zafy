# Zafy — site web

Page de présentation de Zafy (React + Vite + TypeScript). L'app mobile est dans `../zafy_mobile`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # site statique dans dist/
npm run lint
```

Le lien de téléchargement de l'APK se règle dans `src/App.tsx` (`APK_URL`).
